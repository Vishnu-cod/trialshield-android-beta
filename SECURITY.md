# Security reporting

This is a **debug-signed testing APK**, not a hardened production build. Do not enter passwords, payment card information, or highly sensitive personal data into TrialShield.

Please do not post sensitive logs, passwords, email contents, subscription invoices, account IDs, or private APK-signing material in public issues. For now, describe reproducible technical issues without personal information.

If you identify a security issue that might expose user data, avoid posting exploit details publicly. The repository owner should enable GitHub's private vulnerability reporting or provide a dedicated private contact method before wider distribution.

Do not bypass Play Protect or any serious security warning to install this preview.
